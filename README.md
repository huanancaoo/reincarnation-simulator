# ☯️ 投胎模拟器 · 轮回司办事处 (Reincarnation Simulator)

一款融合了全球人口真实出生概率、现代搞笑梗与东方玄幻修真分支的单机网页文字模拟游戏。

体验地址：**[http://localhost:5173/](http://localhost:5173/)**

---

## 🌟 游戏核心机制

1. **命格十连抽（Talent Selection）**：
   - 包含普通（白）、稀有（蓝）、史诗（紫）、传说（金）、神话（红）五种稀有度。
   - 涵盖现实与奇幻趣味天赋，如「纯血天生牛马」、「拆迁二代」、「书香门第」、「灵根觉醒」、「罗马原住民」、「机械飞升者」等。
2. **六维资质加点（Attribute Allocation）**：
   - 20 点先天资质自由分配至颜值、智力、体魄、家境、气运。
   - 提供「均摊分配」、「智商拉满」、「财运亨通」、「随机点数」快捷预设。
3. **投胎大转盘（Reincarnation Roulette）**：
   - **降生地域**：包含北欧极乐（高福利）、瑞士阿尔卑斯、中国一线城市、东非大草原、恒河平原，以及隐藏的南极科考站、火星前哨太空穹顶等。
   - **家庭阶层**：跨国财阀、院士世家、富商名贾、双职工中产、工薪百姓、清贫寒门。
4. **人生演化引擎（Life Simulation Engine）**：
   - 0 岁到 100+ 岁丰富事件流，包含抓周启蒙、奥数中高考、恋爱成家、创业财富自由、中年健康危机、老年天伦之乐。
   - **隐藏分支**：
     - **修仙飞升线**：引气入体 -> 渡劫金丹 -> 白日飞升上界。
     - **赛博永生线**：脑机接口 -> 量子演进 -> 意识上传戴森网络。
   - 播放控制：支持 1x / 2x / 5x 变速推进、单步点进、瞬间推演到终局。
5. **功德 Roguelite 元养成（Karma System）**：
   - 每一世根据寿元、善行、成就发放功德值。
   - 功德值越高，下一世十连抽高级金色/红色天赋的概率越高！
6. **成就阁与生死簿结算（Achievements & Post-Mortem）**：
   - 收集 11+ 种特色成就（「期颐之年」、「白日飞升」、「富可敌国」、「人类灯塔」等）。
   - 生成专属墓志铭与一键复制生平分享长文。

## 🛠️ 本地运行与构建

```bash
# 进入项目目录
cd /Users/huanancao/.gemini/antigravity/scratch/reincarnation-simulator

# 安装依赖
pnpm install

# 运行本地开发服务器 (默认端口 5173)
pnpm dev

# 执行自动化测试 (基于 Vitest)
pnpm test

# 打包生产版本
pnpm build
```

## 🎨 技术架构

- **前端框架**：React 18 + TypeScript + Vite 6
- **样式与动画**：Tailwind CSS + 现代 CSS `@starting-style` 离散平滑过渡动效
- **音效合成**：原生 Web Audio API 振荡器实时调频合成（无需外部音频文件）
- **图表与粒子**：Canvas-Confetti + 动态 SVG 徽章
- **数据持久化**：原生 LocalStorage 存档（跨会话保存功德与成就）
